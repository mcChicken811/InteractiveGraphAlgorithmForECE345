# InteractiveGraphAlgorithmForECE345

An interactive graph builder for stepping through graph algorithms in the browser: breadth-first search, depth-first search, and Prim's and Kruskal's minimum spanning tree algorithms.

## Opening the website

Open `index.html` in a web browser, for example by double-clicking it. No installation, build step or server is needed: the compiled app (`build/app.js`) is included in the repository.

## More

See [DOCUMENT.md](DOCUMENT.md) for how to use the editor and the algorithms, how to rebuild after changing the source, and how to run the tests.
